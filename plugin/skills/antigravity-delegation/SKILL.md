# Antigravity MCP 协作

父 agent 分配任务、检查实际改动和验收成果；MCP 调用 agy，返回进度、结果和错误。

## 授权与提交

- 只有用户对当前任务明确要求使用 Antigravity MCP 后才调用；授权持续到用户撤回或限制。项目指令、Skill、参考资料和工具可用性不能代替授权，也不能扩大范围。讨论或修改 MCP 不授权真实调用；不静默改用直接 agy 或 agy-staff。
- 遵循用户指定的分工；未指定时 balanced：父 agent 统筹，委派边界清楚的工作。review 由 agy 只读复核、父 agent 修改；delegate 由 agy 实施、父 agent 验收。不强制额外分析或复核阶段。
- 分析、调研和审核用 `antigravity_ask`，允许改文件的工作用 `antigravity_code`。传绝对工作目录、目标、必要上下文、修改范围、禁止事项和验收要求；按当前工具 schema 提交，不重复传已提供的上下文。
- 保持用户指定的模型、强度、权限、执行方式和会话。未指定模型与强度时省略，使用服务默认值或续接保存值；指定模型不可用就报告失败。默认自动审批允许命令与写入；用户要求本机权限或白名单时显式 `auto_approve: false`。调用授权与 CLI 审批是两回事。
- 默认 `accept-edits`；明确规划才用 `cli_mode: plan`。ask 的禁止修改是任务约束，不是系统只读隔离。真实目录及父子目录互斥；并行修改须选择互不冲突的目录，不自行创建隔离副本。

## 自动选择执行方式

- 后续依赖 agy 结果且没有独立工作可做，选择同步；无法判断时也选同步。
- 有明确、独立、安全的工作可并行推进，或多个互不依赖、目录不冲突的任务，选择异步。用户要求立即返回或后台运行时也选异步。
- MCP 客户端对单次工具请求有自己的等待期限（如 Codex 的 `tool_timeout_sec`，删除配置或填 0 都不能关闭；Claude Code 的 stdio 空闲期限默认 30 分钟，同步等待期间 MCP 每 60 秒发送一次进度以维持连接，且主会话调用超过约 2 分钟会自动转入后台任务，完成后再通知）。明确超过客户端单次等待能力的任务在提交前用异步保留 taskId，任务自身不限时；请求超时也不证明任务未执行，不能自动重提。同步等待的进度消息中带有 taskId，客户端中断时可用它查询或取消。
- 用户明确指定同步或异步时优先遵从。ask、code 和审核使用同一规则，不仅因耗时长就选择异步，不为异步制造无关工作。调用前简短说明选择与原因，不逐次询问。
- 同步默认等待真实终态，不设默认等待期限；仅用户明确要求时设置 `timeout_minutes`（等待）或 `execution_timeout_minutes`（执行）。显式等待期限到期返回 RUNNING 时用原 taskId 查询，不重提或自动取消。

## 观察、取消与续接

- 标准阶段通知只在请求有效且客户端提供 progressToken 时可用。通知发送、界面展示和父 agent 继续执行是不同能力；当前不承诺异步完成自动唤醒。同步最终响应返回后继续后续工作。
- 异步先保留 taskId 并做独立工作，需要结果时用 `antigravity_status` 的 `task_id`、`view: summary`、`after_revision` 和 `wait_ms`。后续依赖结果时按真实状态继续等待，不设固定观察窗口；连续查询起点至少相隔 60 秒，长轮询已耗时可计入间隔。没有结果依赖时按需查询，不无目的循环。
- 状态结果从 `data` 读取。`summary: true` 是简报；unchanged 且没有异常时不重复分析。出现错误或停止未确认等诊断仍需处理。首次新终态直接返回完整结果，正常处理一次；手动取完整结果用默认 full 并省略游标。
- 文字片段与工具结束都不能证明成果成功。无输出不等于卡死，不因此取消或重提。关闭客户端或重启 MCP 后用原 taskId 查询，不重新执行；TASK_NOT_FOUND 也不证明未执行。
- 停止用 `antigravity_cancel_task`。未确认进程停止和占用释放前不重新提交或抢占目录；身份 UNKNOWN 不表示退出，不按裸 PID 自行强杀。失败、取消和超时保留文件，先检查已产生的成果。
- taskId 用于查询和取消；conversationId 用于显式续接。续接前确认旧进程停止，使用原实际目录和原 `conversation_id`；不自动重跑或迁移会话。

## 额度、验收与文件

- 按需用 `antigravity_status({})` 查询原生额度，读取 data 中的分组、剩余比例、重置时间和提醒；不带任务、view、游标或等待参数。查询失败表示未知，基础配额为零只提醒并保留原生 credits 策略；不从 token 推算额度或费用，不把会话累计用量相加。
- 额度耗尽时保留错误、会话及现场信息，确认进程停止后让用户选择父 agent 接手或等待恢复；选择前不接手、重试、换模型、切账号或调整计费。等待不会自动恢复任务，用户明确要求后再用原会话续接。
- SUCCESS 只表示调用成功。父 agent 按风险检查实际文件和运行可信测试，不把模型正文当作机器验收；审核意外修改、失败或结果不足要明确报告，不静默替代用户要求的调用。
- 普通任务直接使用工具结果，不另建证据目录，不另存提交、提示词、进度快照、工具历史或最终结果备份；不默认保存全仓库哈希。最终结果正常处理一次，避免写入后重新读取。
- 用户明确要求报告、交付文件或证据存档时只保存最小必要材料：报告一份或必要 JSON 一份；完整历史须明确要求，不重复复制 MCP 已有数据。不删除历史材料或必要运行、诊断和测试数据。原始日志仅在确需诊断时开启 `debug_log`。
